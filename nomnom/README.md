# NOMNOM

`MiG29Fulcrum.json` is the manifest submitted to [NOMNOM](https://github.com/KopterBuzz/NOMNOM) (the mod registry used by NOMM),
in KopterBuzz/NOMNOM#402. NOMNOM updates it from this repository's GitHub releases (it takes the first asset, the
`MiG-29-Fulcrum_<version>.zip` built by `tools/build_mig29.ps1`). Keep this copy in sync if the listing changes.
